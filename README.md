# Medieval Forge — лаунчер и обновления

Сборка: Minecraft 1.20.1, Forge 47.4.13, Windows 11.

## Для друзей

Скачайте из последнего релиза два файла из папки `launcher`:
`Medieval Launcher.cmd` и `Medieval Launcher.ps1`. Положите их в одну папку и запустите `Medieval Launcher.cmd`.

Скрипт:
- скачивает последнюю опубликованную сборку;
- проверяет SHA-256 скачанного архива;
- обновляет только папку сборки в `%APPDATA%\.minecraft\Medieval Forge`;
- устанавливает Forge 47.4.13, если он ещё не установлен;
- создаёт профиль **Medieval Forge** в официальном Minecraft Launcher.

Minecraft Launcher должен быть установлен и в него нужно войти под лицензированным аккаунтом. Для первой установки Forge нужен Java 17; обычно скрипт находит Java, установленную Minecraft Launcher. Если Java не найдена, установите Temurin 17 и запустите лаунчер снова.

## Как выпустить обновление

1. Откройте PowerShell в папке `publisher`.
2. Запустите:
   ```powershell
   .\Build-Pack.ps1 -Version 1.0.0
   ```
3. В GitHub откройте **Releases → Draft a new release**, создайте тег `v1.0.0`.
4. Загрузите оба файла из `publisher\release\1.0.0`: архив сборки и `manifest.json`.
5. Нажмите **Publish release**.

Следующий запуск лаунчера у друзей скачает эту версию. Папки `saves`, `screenshots`, `logs` и личные настройки не попадают в релиз и не удаляются при обновлении.

## Важно

В публичном репозитории файлы сборки доступны любому. Убедитесь, что лицензии модов разрешают их распространение.
